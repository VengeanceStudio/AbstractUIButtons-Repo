# Abstract UI Buttons (v12.0.51)
# v12.0.51: WoW 12.0 API Alignment

This release provides essential compatibility updates for the latest World of Warcraft Interface (12.0.0). It ensures that all features remain functional while following the updated Blizzard Settings API requirements.

### 🚀 Highlights
* **Interface 12.0 Support:** Updated `.toc` and internal logic to support World of Warcraft 12.0.0.
* **Feature Retention:** Maintained all existing functionality, including the Right-Click shortcuts for options and the Addon Manager toggle.
* **Profile Safety:** Reinforces protection for Default and Active profiles during deletion.
* **Code Readability:** Enhanced commenting throughout the Lua source to explain complex logic blocks and API interactions.

### 🛠 Improvements
* **Settings API Compliance:** Updated registration logic for the Blizzard Options menu to ensure a smooth user experience in modern WoW.
* **Database Stability:** Refined initialization to handle persistent variables across client versions safely.

## 📦 Installation
1. Download the latest release.
2. Extract the `AbstractUIButtons` folder into your `World of Warcraft/_retail_/Interface/AddOns/` directory.
